# SunamoDevCodeBase

## Short description

Základní typy, sdílené utility a veřejná rozhraní vyčleněné z monolitu SunamoDevCode. Obsahuje argumenty pro generování vlastností, práci se soubory a čištění XLF, enumy pro přístupové modifikátory, TypeScript typy a šablony pro generování C# kódu. Je to NuGet balíček, na kterém stavějí další SunamoDevCode* balíčky.
